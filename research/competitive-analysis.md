# 競合調査(2026-08-15 実施)— 音声操作×育児記録アプリの国内外全景

> 調査方法: Web検索+一次情報(公式サイト・プレスリリース・App Store)の突き合わせ。2エージェント並列調査の統合版。

## 結論(プロダクト戦略に効く3行)

1. **「スマホ単体で voice-in / voice-out が完結する授乳トラッカー」は国内・海外ともに存在しない。** これが本プロダクトの唯一性。
2. 音声**入力**だけなら海外は既にレッドオーシャン化しつつある(2024〜26のAI新興勢)。差別化の核は「**読み上げ(耳で完結)+左右タイマー+スマートスピーカー不要**」。
3. 最大の実質競合は「Echo を持つ家庭の Alexa スキル」。→「スピーカー不要・外出先でも・タイマー付き」で切り返す。

## 国内

### ぴよログ(最有力・デファクト)
- 音声授乳タイマー(2021-11-10、「世界初」): コマンドは「左」「右」「ストップ」のみ。
  - **iOS 14.5+ 限定**(公式PRに「Androidで利用することができません」と明記)。
  - **読み上げなし**。公式注記「声の操作でも画面を見て確認してください」= 画面前提。
  - タイマー画面を開いた状態でのみ動作。バックグラウンド不可。
- Alexa 対応(2020-09): 「寝る/起きる/おしっこ/うんち/両方」の5項目のみ。授乳の左右・分数は非対応。
- 最新版 9.2.8(2026-08時点): Live Activities・ウィジェット強化。**読み上げ機能の追加なし**。
- 出典: https://prtimes.jp/main/html/rd/p/000000013.000019025.html / https://www.piyolog.com/news.html

### その他国内アプリ
- 授乳ノート(カラダノート): 音声機能なし。片手タップUIが売り。
- パパっと育児@赤ちゃん手帳: Siriショートカットで7種類の記録(「Hey Siri, 母乳」等)。読み上げなし。
- ベビレポ: Siri/Alexa/Googleアシスタント対応を謳うが、コマンド範囲は限定的。読み上げ確認できず。

### 国内 Alexa スキル(= 読み上げの既存反例)
- **あかちゃんきろく**(paco): 「左のおっぱい」「ミルク50ミリ」で記録、「最後のおっぱいはいつ?」に**音声で回答**。国内で唯一明確な voice-out。ただし Echo/Alexaアプリ前提。
- 育児日記(t_momo_t): 同様に記録+読み上げ回答。
- → 「音声完結」自体は Alexa 経由なら存在する。本プロダクトの主張は「**スマホ単体で**」に限定すること(発信・ストア文言でも誇大にしない)。

- 業界背景: Amazon Baby Activity Skill API は 2020-05 廃止、Google Assistant 対話型 Actions は 2023-06 全廃。→ スマートスピーカー経由の育児記録エコシステムは縮小しており、**スマホ単体完結の価値が相対的に上がっている**。
- 資金動向: Joy Parenting Club が 2025-11 に $14M 調達(チャット型AI)。育児×AIには投資がついている。

## プラットフォーム状況(2026-08)

- Google アシスタント: 2026-09-04 からモバイルで順次廃止、Gemini に置換。Gemini のサードパーティアプリ操作(App Functions)は大手限定で未開放。→ **Android はアシスタント連携に頼れない。アプリ自前のリスニング(FGS)一択**。
- iOS: App Intents / Siri は健在。**アプリ非起動でもインテント実行+Siriが応答文を読み上げ可能**。ぴよログが使っていない最大の武器。
- EU DMA により App Functions 等の開放が進む見込み(時期未定)。中期的には Android の音声経路が広がる可能性。

## 命名・訴求上の注意

- 「世界初」を名乗る場合は「**スマホ単体で音声入力と音声読み上げが完結する授乳記録アプリとして**」と限定句を付ける(ぴよログが「世界初の音声操作授乳タイマー」を既に名乗っており、Alexaスキルに読み上げ実例があるため)。
- 景表法・ストア審査の観点でも限定句必須。
