# Nenelog

Nenelog is a bilingual baby-care tracker designed for hands-free use: speak a command,
record the event, and hear the result without looking at the screen.

The project is currently under active development for RevenueCat Shipaton 2026.
Its first vertical slice is an offline-capable nursing timer with left/right switching,
spoken responses, and persistent local history on iOS and Android.

## Technology

- Kotlin Multiplatform
- Compose Multiplatform
- SQLDelight
- Native iOS and Android speech integrations

Speech audio is not sent to or stored on Nenelog-operated servers.
