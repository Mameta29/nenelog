# 01. プロダクト仕様 — Nenelog

## ビジョン

**「新生児期の親から『スマホの画面』を取り上げても、記録が続くようにする。」**

授乳・育児記録は1日8〜12回発生し、毎回両手が塞がっている。既存アプリはすべて「画面を見てタップする」ことを前提にしており、深夜・抱っこ中・搾乳中に破綻する。Nenelog は音声を第一級の入出力にすることで、記録行為そのものを消す。

## ペルソナ

### P1: 産後0〜6ヶ月の母親(メイン)
- 1日8回以上授乳。夜間授乳で睡眠分断。左右どちらから始めたか思い出せない。
- 授乳中はスマホを触れない/触りたくない(赤ちゃんを支えている・暗い・眩しい)。
- 既存アプリ(ぴよログ等)ユーザー。記録は好きだが「記録のための操作」が苦痛。

### P2: 育児参加するパートナー(じゃけえ本人がモデル)
- ミルク・おむつ・寝かしつけ担当。記録の共有で「さっき飲ませた?」の聞き合いを無くしたい。
- ガジェット好き。音声操作に抵抗がない。

### P3: アクセシビリティニーズのある親(Peace Prize の核)
- 視覚障害のある親: 画面UIが使えない/使いにくい。voice-in/voice-out はそのまま支援技術になる。
- 帝王切開後・腱鞘炎・双子育児: 物理的に手が使えない場面が多い。

## 機能仕様

### 音声機能(プロダクトの心臓)— 3段階の音声レベル

| レベル | 名称 | 動作 | プラットフォーム |
|---|---|---|---|
| L1 | プッシュトゥトーク | ウィジェット/クイック設定タイル/アプリ内マイクボタンをワンタップ→1発話で記録(「ミルク80」「うんち出た」) | iOS/Android |
| L2 | **セッションモード** | 授乳セッション開始後、画面オフ・ポケットの中でも連続リスニング。「右」「交代」「ストップ」「今何分?」に**音声で応答** | iOS/Android |
| L3 | 完全ハンズフリー | 「Hey Siri, 右スタート」→ アプリ非起動でも記録開始、Siriが応答を読み上げ。「Hey Siri, 授乳どのくらい?」→ 経過時間を読み上げ | iOS(App Intents)。Android は L2 で代替 |

### 音声で記録できるイベント(全網羅)

- 授乳(左右・タイマー・切替) / ミルク(量) / 搾乳(左右・量)
- おむつ(おしっこ/うんち/両方、量・ゆるさのオプション)
- 睡眠(寝た/起きた) / 体温 / 薬・ビタミン / お風呂
- **自由メモ**: 「メモ、今日初めて笑った」→ そのまま保存+AI構造化(P1機能、`07`参照)

### voice-out(読み上げ)の仕様 — 世界初の部分

- タイマー照会: 「今何分?」→「右side、12分です」
- 前回照会: 「前回の授乳は?」→「2時間15分前、左から10分と右5分です」
- 今日のサマリ: 「今日のまとめ」→「授乳7回、ミルク160ml、うんち2回です」
- 全read-back文の台本は `05-voice-ux.md`。

### 画面UI(音声と同格の完成度で作る — Design Award 要件)

- ホーム: 今日のタイムライン+次回授乳予測。ワンタップ記録ボタン(音声を使わない人も完全に使える)
- 授乳タイマー画面: 左右大ボタン。**リスニング中の呼吸するようなアンビエント演出**(音声状態の可視化がデザインの見せ場)
- サマリ/グラフ: 日次・週次。授乳間隔・睡眠パターン
- 家族共有: リアルタイム同期、誰が記録したかの表示
- ナイトモード: 純黒背景+最低輝度+赤系アクセント(暗所で眩しくない)。22時〜6時は自動でナイトモード
- ウィジェット(iOS/Android)・Live Activities(iOS、進行中タイマー表示)・クイック設定タイル(Android)

### アクセシビリティ(Peace Prize 要件、後付けにしない)

- VoiceOver / TalkBack 完全対応(全画面。CI でアクセシビリティ監査を回す)
- Dynamic Type / 大文字対応、WCAG AA コントラスト
- 音声UIは晴眼者向け機能であると同時に視覚障害の親の主要導線 → **音声機能の中核部分はアクセシビリティ用途では無償提供**(`07`参照)

## スコープ階層(「MVPではなく完成品」をスケジュールと両立させる装置)

- **P0(9/20 ストア提出に必須)**: L1+L2音声(日英)、voice-out全種、授乳/ミルク/おむつ/睡眠/メモ記録、タイマー、ホーム+タイムライン+サマリ、家族共有(2人)、ナイトモード、RevenueCat課金+ペイウォール、OneSignal基本通知、iOS App Intents(L3)、VoiceOver/TalkBack、日英ローカライズ、iOS+Android同時リリース
- **P1(9/30までに v1.1 として入れば加点)**: AI自由メモ構造化、Live Activities、ウィジェット、Galaxy Store公開+フォルダブル対応、Stripe Webファネル、Layers実験、成長記録(体重/身長)
- **P2(Shipaton後)**: Apple Watch、搾乳量トラッキング強化、多言語(中韓西)、離乳食記録、小児科受診用レポートPDF

> 判断ルール: P0 を脅かす作業は、どの賞の加点になろうと後回し。迷ったら `12-schedule.md` の週次ゲートで判断。

## 非スコープ(明確にやらないこと)

- 広告(Catvertising賞は捨てる。育児アプリに広告はブランド毀損。理由は `02` に記載)
- 泣き声解析・睡眠解析などのAI分析(競合SciBaby等の領域。本質でない)
- スマートスピーカー用スキル開発(スマホ単体完結が価値の核。Alexaスキルは作らない)
- 医療アドバイス(記録に徹する。授乳量の推奨等は一切表示しない — 薬機法・ストア審査リスク)
