# 09. デザインシステム — Design Award を獲りにいくUI/モーション

> 審査観点=「アプリ開発のクラフト。革新的アイデア and/or 美しいデザイン・アニメーション」。本アプリの独自性は**「音声の状態を目と手に翻訳するデザイン」**。

## 確定したデザイン方向（2026-09-04）

名称は **Quiet Linen**。比較HTML `web/ui-concepts.html` の4案から、次の組み合わせに確定した。

- **Aを全体の基本デザイン**にする: 温かな生成り、落ち着いたセージ、必要最小限の立体感、大きく迷わない操作領域
- **Bのタイムライン表現**を取り込む: カードを積み重ねず、日誌のような罫線・時刻列・余白で記録を見せる
- **Cをナイトモード**として取り込む: OLED純黒、クリーム文字、減光アンバーだけで深夜の眩しさを抑える
- Dの標準的な操作規則はアクセシビリティの参考にするが、青中心のネイティブ外観は採用しない

これは画面ごとに別のスタイルを混ぜる方針ではない。角丸、書体、間隔、アイコン、状態表現はQuiet Linenの一系統に統一し、Bから借りるのは**記録一覧の情報設計**、Cから借りるのは**夜間用カラーテーマ**に限定する。

## ブランド

- 名前: Nenelog（ネネログ。2026-08-15確定、経緯は `research/naming-check.md`）
- トーン: 深夜3時に優しい。静けさ・呼吸・ぬくもり。疲れている人を急かすポップさ、医療機器の冷たさ、AIサービス特有の紫グラデーションを避ける
- デザイン原則:
  1. **今の状態が最初に分かる**: 記録より先に、計測中の側・時間・音声状態を見せる
  2. **片手で間違えない**: 主操作は親指圏内、48pt以上、同じ場所で完了できる
  3. **夜に眩しくない**: 夜間は色数と面発光を減らし、純黒を積極的に残す
  4. **記録は日誌として残る**: 過剰なカードUIではなく、時間の流れを罫線と余白で表す
  5. **声の状態を隠さない**: 待機・認識・応答・エラーを、文言と形と動きの3つで伝える
- アイコン: 三日月+音波のモチーフ（1024×1024、Devpost要件）。アプリ内は原則2px相当の線画で統一

## カラートークン

### ライト（Quiet Linen / A）

| 用途 | Token | 値 | 使用ルール |
|---|---|---:|---|
| 画面背景 | `canvas` | `#FAF6F0` | 全画面の生成り。純白の大面積は避ける |
| 基本面 | `surface` | `#FFFDF9` | タイマーなど意味のあるまとまりだけ |
| 静かな面 | `surfaceQuiet` | `#F1ECE4` | 補助情報、未選択コントロール |
| 本文 | `ink` | `#213229` | 見出し・本文・主要数値 |
| 補助文字 | `inkMuted` | `#68726C` | AAコントラストを維持する最薄文字 |
| 操作色 | `sageStrong` | `#3D6652` | 主ボタン、選択状態、フォーカス |
| ブランドセージ | `sage` | `#8FAE9B` | 面・図形・波形。小さい文字には使わない |
| 淡いセージ | `sageSoft` | `#DCE8DF` | 音声状態や選択前の背景 |
| 強調色 | `terracottaStrong` | `#A4513F` | 停止、取り消し、重要な状態。限定使用 |
| 装飾色 | `terracotta` | `#D98E73` | 大きな面や非テキスト装飾のみ |
| 境界線 | `divider` | `#DED8CE` | タイムライン、セクション境界 |

`sage` と `terracotta` はブランド色、`sageStrong` と `terracottaStrong` は可読性を満たす操作色として分ける。色をそのまま文字に流用しない。

### ダーク

- 背景 `#12141C`、面 `#1B1E27`、主要文字 `#F5F1EA` を基準とする
- 日中・夕方にOS設定へ追従する一般ダークテーマ。深夜特化のナイトモードとは別物
- セージ/テラコッタはライトより彩度を約10〜15%落とす。配色値はCompose実装時にコントラストテストで確定する

### ナイト（Night Signal / C）

| 用途 | Token | 値 | 使用ルール |
|---|---|---:|---|
| 画面背景 | `nightCanvas` | `#000000` | OLED純黒。余白を塗りつぶさない |
| 必要な面 | `nightSurface` | `#120D09` | 操作にまとまりが必要な場所だけ |
| 主要文字 | `nightInk` | `#FFEDD7` | 純白は使わない |
| 補助文字 | `nightMuted` | `#A5917C` | 小さい説明はAAを実測する |
| 強調/停止 | `nightAmber` | `#B34D2F` | 1画面の強調箇所は原則1つ |
| 境界線 | `nightDivider` | `#3D3026` | 影の代わりに使う |

- 22:00〜06:00に自動切替し、設定で自動/手動を選べる
- 青、純白、大きな明色面、グラデーション、発光シャドウを使わない
- タイムラインは黒地に細い罫線だけとし、記録ごとのカード背景を置かない
- OSの「視差効果を減らす」「透明度を下げる」「コントラストを上げる」を尊重する

## タイポグラフィ

- 日本語/英語UI: LINE Seed JPを第一候補、未搭載時は各OSのシステムサンセリフへフォールバック
- Bの編集的な雰囲気は明朝体の多用ではなく、**余白・罫線・時刻列・見出し階層**で作る。操作UIの書体は増やさない
- タイマーと時間は必ずタブラー数字（等幅数字）
- 最小本文は14sp相当。補助ラベルは12sp相当まで許容するが、重要情報には使わない
- 見出しは太さで威圧せず、サイズと余白で階層を作る。全大文字や過剰な字間は英語の短いラベルだけ
- Dynamic Type / fontScale 200%でも、省略によって「左右・時間・状態・停止」が欠けない

## レイアウトと形

- 8ptグリッドを基本に、画面左右余白20pt、セクション間24〜32pt
- 標準カード角丸24pt、補助面14〜16pt、主ボタン16〜18pt、状態pillは全丸
- 影はライトテーマの主要カードにごく薄い1段だけ。タイムライン、ナイトモード、入れ子カードには使わない
- 1画面に塗りつぶしの主ボタンは原則1つ。二次操作は輪郭またはテキスト
- すべての操作領域を48×48pt以上にする。表示上小さいアイコンにも透明な操作余白を付ける
- ホーム下部の記録バー、タイマーの左右切替、停止は親指到達範囲に置く
- Compose/iOS間で見た目を完全一致させるより、同じトークン・情報階層・操作意味を守る

## タイムライン（Care Journal / Bを統合）

- 日付見出し → 細い罫線 → 記録行、の縦の流れを基本とする
- 記録行は `時刻 | 種別アイコン+内容 | 補助情報`。時刻列の幅を固定し、縦に走査しやすくする
- 個々の記録を浮いたカードにしない。行間とhairline dividerで区切る
- 授乳は「左 8分 / 右 6分」、ミルクは量、おむつは種別など、最重要値を1行目で完結させる
- 音声記録、手動修正、同期状態などは2行目の補助情報へ落とす
- 計測中の記録と直前の取り消し対象だけ、淡いセージ面または左端の太線で強調する
- 日付をまたぐ一覧は日付見出しをstickyにしてよいが、コンテンツを隠さない
- 削除はスワイプだけに依存せず、詳細画面にも明示操作を用意する

## 音声状態のデザイン言語（独自性の核）

画面を見ないアプリだからこそ、見た時の状態表現に全投資する。

| 状態 | 視覚 | 状態説明（例） | ハプティクス | 音 |
|---|---|---|---|---|
| 待機 | 画面下部に静かな水平線 | 音声操作は待機中 | — | — |
| リスニング中 | 線が呼吸のように4秒周期で波打つ | 聞いています。「右スタート」と話せます | 開始時1回 | 短いソフト音（設定でオフ） |
| 認識した瞬間 | 波が一度だけ大きくうねり発話テキストが浮かぶ | 「右スタート」を認識しました | 1回 | — |
| 応答中（TTS） | 波が話すリズムで揺れる | 応答を読み上げています | — | TTS |
| エラー | 波がほどけて点線になる | 聞き取れませんでした。もう一度どうぞ | 3回短 | — |

- 波形だけで状態を伝えず、必ず可視テキストとアクセシビリティ状態説明を併記する
- 無限パルスや速い動きは避ける。Reduced Motion時は波形を静止線+状態アイコンへ置換する
- タイマー画面は左右の乳房を抽象化した2つの円と、超大型タブラー数字を使う。走行側は4秒周期で穏やかに明滅する
- アニメーションはComposeの`animate*`+カスタム波形Canvas。60fps維持をscreenshot/性能テストで担保する

## 画面別の要点

- ホーム: 「今」を最上部に置き、前回授乳からの経過を大きく表示。次に明示的な音声状態、クイック記録、B型タイムライン。FABではなく下部固定の記録バー
- 授乳タイマー: 計測中の側と総時間を最優先。左右切替と「停止して保存」を同一視野内に置く
- まとめ: 日/週の数字は3〜4個に絞り、グラフは比較対象と単位を音声/スクリーンリーダーでも説明する
- ペイウォール: `docs/07-monetization.md` の深夜長押し仕様。RevenueCat Paywallsの構造を保ちながらQuiet Linenへ合わせる
- オンボーディング: 3枚以内。1枚目で音声デモを実際に体験させ、マイク許可の文脈を作る
- 空状態・読み込み・権限拒否・オフライン・音声失敗をすべて日英で設計する

## アクセシビリティ（Peace Prizeと共通）

- 全画面VoiceOver/TalkBackラベル・トレイト・フォーカス順序を設計する
- 認識状態の変更は`liveRegion`相当で通知するが、partial結果ごとの読み上げでユーザーを妨げない
- Dynamic Type最大サイズ / Android fontScale 200%でレイアウト崩れゼロをscreenshot testに含める
- WCAG AAをライト/ダーク/ナイトの全組み合わせで自動検証し、色以外の手掛かりを併用する
- タッチターゲットは両OSとも48pt基準。スワイプ、長押し、音声だけに依存する操作を作らない
- TTS中・認識中・保存済みをアクセシビリティ用状態説明にも反映する

## 実装時の禁止事項

- 紫/青グラデーション、ガラスカード、強いドロップシャドウなど、生成AIサービスに多い装飾を持ち込まない
- すべての情報を別カードに分割しない。背景の上にカードを重ね、その中にさらにカードを置かない
- Bのえんじ色や明朝体を全画面へ移植しない
- Cの黒テーマを通常ダークテーマと混同しない
- 小さい低コントラスト文字、色だけの状態差、44pt未満のタップ領域を許容しない
- プラットフォームごとの都合で文言や情報階層を変えない。日英stringsと状態モデルを共有する
